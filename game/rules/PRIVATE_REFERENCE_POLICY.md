# Private reference policy
2018 Basic Rules remain primary. 2014 Player's Handbook, Dungeon Master's Guide and Monster Manual fill gaps after mechanical verification. Supplementary books are opt-in, with original and revised creature/race definitions kept separate. The supplied Blood Hunter document explicitly targets 2024 mechanics and is not part of original-edition RAW. Private PDFs, extracted page text, non-SRD stat blocks, tokens and character-sheet templates stay local outside game/. No API keys or player databases are published. The public game can start without private references; optional asset previews require the local reference/assets library. The GitHub rules database uses verified gzip transport of the same SQLite file as the Windows ZIP. Do not treat page extraction as implemented game mechanics.
