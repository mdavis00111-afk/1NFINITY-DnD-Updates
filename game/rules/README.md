# 2018 Basic Rules foundation
Source: November 2018 Basic Rules v1.0, 180 pages. Local personal-use archive contains extracted page text and text-block coordinates, organized in 22 categories. Do not place the original verbatim archive in the public repository. Private repository transfer requires authenticated update support and verified privacy first. Text retrieval is not equivalent to executable rules. Complex tables require validation.
The source fully describes only four core races (with subraces) and four classes; other options and complete world generation are not supplied. Never invent missing rules.
This release implements a local import/search UI and a limited level-one draft calculator: 4d6 drop lowest or standard array, automatic score allocation by class, racial ability bonuses, modifiers, saving throw bonuses, base HP, speed, initiative and unarmored AC. Class score priority is a quick-generation policy, not a mandatory rule. Manual score allocation, skill selection, traits, equipment, spells, character persistence, NPCs, combat and world generation are pending.
