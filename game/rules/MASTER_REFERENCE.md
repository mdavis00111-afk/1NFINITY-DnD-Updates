# Master reference
The recovery ZIP installs separate local 2018 Basic Rules (180 pages) and SRD 5.2.1 (364 pages) reference libraries beside Godot.exe. The 2018 personal reference is not published to this public repository. Revised SRD mechanics must never silently replace the existing original-5e draft mechanics. All reference extraction and candidate creature fields are unvalidated until rule-specific mechanical tests are implemented. Character options and creature catalogs are accessible in Settings > Rules Library > Master Reference. The reference folder is outside the update-managed game directory.
