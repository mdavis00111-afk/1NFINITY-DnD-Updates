# Character system — 0.0.11
Authoritative rules: 2018 Basic Rules; original 2014 SRD 5.1 fills gaps. No 2024 mechanics. Catalogue: 20 indexed tables, 12 classes, 9 races, 7 subraces, 12 SRD subclasses, 6 backgrounds, 18 skills, 319 spells, 246 equipment entries, 407 class features, 290 progression records, 42 traits and 362 magic item entries. This is the SRD subset with 2018 mechanical supplements, not the complete PHB.
Manual wizard: identity/portrait; rolled scores, array or point buy; proficiency/features/spells; class and background equipment packages/review. Quick generation uses the same rules. Shared reference pane and option tooltips use stable catalogue IDs; Settings > Rules Catalogue browses all 20 tables.
Persistence: versioned JSON user://players/v1, local copied portraits, unique IDs and archive. Campaign template function clones the master record. SQLite deferred; preserve IDs in future migrations. Draft and needs_review records are excluded from campaign templates. Ready refers to the current supported creator and is not a certification of complete RAW or a finished gameplay engine. No full PHB supplied; non-SRD subclasses, variants, spells, feats and additional backgrounds remain gaps. Other pending mechanics: Ranger humanoid pairs and language checks, starting wealth shopping, custom backgrounds, full equipped loadout control, progression, enemies and gameplay. Original private PDFs remain local. Catalogue attribution in data/2014/ATTRIBUTION.txt.
Font: genuine bundled EB Garamond Italic replaces image-derived runtime glyphs to fix spacing and jagged text. Gold text, hover flourish, approved painted title, Hall of Heroes, borders and ornaments retained. The supplied visual reference remains the design target; the scalable font is an approximation.
