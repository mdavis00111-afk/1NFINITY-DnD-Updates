# 1NFINITY D&D — approved typography direction
Reference: user-approved illustrated character grid showing uppercase, lowercase, numerals, punctuation, symbols and accented characters; warm gold classical serif with fine strokes and flared serifs. The artwork is a visual reference, not an installable typeface.
Implementation: EB Garamond, an SIL OFL-licensed scalable font chosen as an approximation. All menus/submenus inherit the master Theme; menu actions use the shared menu_button.gd. Normal text is warm gold with a dark outline for contrast. Hover and keyboard focus use bright ivory gold, warm shadow and a fading luminous star flourish below the text. No visible button boxes. Existing painted title remains artwork. Build information is small, subtle and bottom right. User-input controls may have readable surfaces.
Do not replace this typography with generic system fonts or introduce boxed main/submenu navigation without approval. Preserve editable text and keyboard navigation. Future gameplay text may require distinct readability styles, but menu identity remains consistent.
