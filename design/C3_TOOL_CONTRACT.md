# C3 deterministic noncombat tool contract
Unpublished source checkpoint; C4/C5 must not activate before native verification. Authoritative local entry point game/gameplay/tool_registry.gd. catalogue() returns version 3 descriptors: tool ID, purpose, mode, exact argument type dictionary, applicable rule-section IDs, expected result. 16 query and 33 mutation descriptors. No keyword dispatch. Exact schemas and nested validation in source. Queries use C2 v2 enquiry envelopes; enquire public, enquire_local trusted-local only. Object profile gives suggested RAW object AC/HP by material, size, resilience; not damage resolution. Equipment options are physical candidates plus actual assignments, not implied clearance. Mutation uses C2 v2 request {schema_version:"2",campaign_id,actor_id,expected_revision,request_id,kind,args}. C4 maps C1 intentions and collects explicit choices (slots/grips, displaced items, targets, quantities, prepared list, hit dice, route). Never infer null as self. Unsupported effects, combat and advancement return explicit errors.

execute(id,req,review:Callable) is trusted local only. Review receives immutable request and campaign/actor/revision/location scope and returns {request_id,campaign_id,actor_id,expected_revision,accepted:bool,ruling:Dictionary,reason:String}. C4/C5 local controller checks player intent, actual contextual facts, consent/access, time/hazards and rule eligibility. Never copy an AI accepted/clearance boolean or allow provider to call execute directly. Ordinary contextual difficulty is a DM category proposal, not a player-chosen DC. Godot maps it to RAW 5/10/15/20/25/30. Circumstances carry evidence event IDs. Check/save ruling exact {seconds:int/null,establish_clock:bool,optional_features_resolved:bool,verified_circumstances:Array,effect_dc:int/null}; source evidence and reviewed circumstances must match; save DC independently verified effect only. Travel uses B2 {difficult,clearance,establish_clock}. No-roll conversation uses observe with {safe_nonmechanical:true,seconds:0,establish_clock:false}; wait/observe use verified duration. Standalone review ruling empty; no arbitrary effect patches.

Standalone mutations use exact C2 request ID, atomic effect+event+settlement+revision+duration+mirrors; not fictional narrative turns. C5 may narrate verified settlements. Narrated checks/saves/observe/conversation/wait/travel adopt v2 then exact raw request binding in B2 read/SQL guard, validate receipt result against request; B4 narration then C2 settle_adopted. recover reconciles receipt or narration already committed; no second roll. Legacy B2 requires marker absent; migrated B2 requires adopted binding. No independent C2 mutator inside adoption. Prepared standalone batch retained locally on ambiguous write; process death loses only uncommitted, never exposed rolls. cancel_uncommitted only after no committed receipt/settlement. execute_sequence bounded 16, stops at decision, failure or pending narration; next request actual revision, never silent rebase.

Supported slice: ordinary level-one complete PC, verified quiet context, standard armor/shield/weapon slots and AC/speed/proficiency, ring/cloak protection attunement, explicit healing-potion variants, self Cure Wounds/Healing Word level 1 slot/components, Life bonus, Second Wind/Lay on Hands self, short/long rest hit dice/resources/slots and cleric/druid/wizard preparation list, local NPC item and denomination transfer, C2 loot, custom/official definitions, NPC/story/party/reconciliation. Custom values are proposals, never official rules or automatic executable effects. Object checks resolve an established instance or disclosed circumstance, not persistent door/lock state or object damage. Known tracked clock and verified rest eligibility needed; 24-hour rule and B2 walking budget reset. Full spells, combat, unsupported resources/conditions and special mechanics not claimed. Native tests pending.
