## Composition
16:9 base 1280×720, scale for 1920×1080 and existing stretch. Use actual container sizing, not absolute positions tied to screenshot. Top header approximately 9% of height: 1NFINITY D&D / AI Dungeon Master (5e) logo left; compact Game, Character, Inventory, Spells, Skills, Quest Log, Map, Campaign, Settings nav. Three vertical main columns approximately 27% / 43% / 29% usable width, gaps narrow, centre largest. Full-height frame, independently scrolling long panels, always-visible input and dice bar; no whole-page scroll. Gold serif (existing approved EB Garamond), navy translucent backgrounds, existing ornate gold frame/button/icon assets, scenic illustration above chat. Readability first; no nested opaque black boxes. Reuse resources, avoid unlicensed or invented assets, no new image-generation dependency. Artwork selected from existing whitelisted campaign thumbnail/scene library; provisional art honestly identified. Screenshot example values and example dialogue are illustrative only.
### Left
Top portrait + name + actual level/class/race; HP current/max with red bar; AC, speed, initiative; six compact ability cells (score/modifier). Proficiency bonus and passive perception. Equipment paper-doll silhouette with head/body/hands/feet/accessory/weapon/shield display slots as reference; only map supported actual equipped armor, weapon and shield record fields, no invented item types/slot mechanics. Empty decorative slots visibly empty; no automatic equipment mutation. Gold/coins and weight/capacity at bottom; display actual coins including denominations as relevant, don't assume all currency converted to gp. Use portrait_art.gd. All stats from campaign actor snapshot, never master character record, do not recalculate from example or stale draft.
### Centre
AI Dungeon Master header; current-location scenery band ~quarter of center height max; scrollable log with distinguishable DM/player/system rows and portraits/role labels. Display committed campaign_created and narration events in correct order; synopsis is not full chat history and must not fabricate events, timestamps or NPC/player speech. Keep existing optional opening generation/retry, failure feedback, single-shot commit and cancellation/navigation behavior from v0.0.23. Initial deterministic opening remains available offline. Composer text box and send/Enter visible; while P3 turn controller absent, explicitly disabled with short honest reason (can connect a signal contract without making a fake turn or persisting player message). Don't call Narrator directly to adjudicate. Manual dice selector d4,d6,d8,d10,d12,d20,d100; quantity bounded, Godot rolls and shows individual values and total. Manual rolls are informational only, no changes to mechanical state or committed turn log, no automatic roll injection; later turn controller owns resolution rolls. No AI rolls. Clear dice feedback, no fake result. Preserve existing campaign exit and opening retry.
### Right
Top independent Inventory / Spells / Skills / Features / Notes switcher. Inventory grid from actual campaign inventory, quantity overlays and equipped indicators; select cell shows catalogue name, category, damage/properties/weight where known. Use existing approved icons if available, fallback labels/icons for missing art, don't use wrong art. Details and lists independently scroll. All Items/equipped filtering optional meaningful function. Spells: cantrips, known/prepared/always-prepared, spell slots remaining/maximum, save DC/attack bonus where applicable; no slot expenditure until mechanics wired. Skills show modifiers/proficiency; Features actual traits/class/background/resources; Notes read actual established world facts or personal notes only if persistence contract exists; avoid fake notes. Quick References buttons for Actions, Conditions, Rules (SRD), Combat, Spells, Equipment route to real existing catalogue/reference views or scoped read-only popup; preserve existing settings/rules access. Party panel shows actual player card and real allies if schema supports explicit party membership; NPC presence is not membership. Empty Add slots disabled until party mechanics implemented. No fake companions.
### Navigation and behavior
Create/Resume existing campaign must open this game workspace in place of current minimal workspace, retain the existing library/synopsis and current opening request flow. On Campaign or Save & Exit, return to correct campaign list, no loss of state. Top Character view uses actual campaign snapshot, not editable master; Inventory/Spells/Skills focus right panel; Quest Log and Map show stored data if meaningful else honest unavailable/empty state without fabricating quest/map coordinates. Settings should return to same campaign rather than losing context; if full settings routing would change unrelated scope, document supported route and retain safe return. Unavailable features visibly disabled or clearly marked, not pretend functioning. No new combat/actions/equip/use/travel/party rules, no schema modifications for this UI milestone. All future action submission through typed controller, not direct Gemini. Read actual campaign store contract and inventory table; if inventory read helper needed, scoped read-only accessor with tests, normalized rows canonical, no arbitrary SQL. Preserve player stores and campaign files.

Actual populated character/campaign data, no baked mockup values. Full layout at 1280×720 and 1920×1080; long names, long dialogue, many items, no caster/with caster, empty inventory, missing artwork, offline/no key, pending and failed opening, resume/delete, no master mutation. New gameplay UI smoke tests using isolated fixtures and existing test infrastructure; run import/runtime if possible, record blocked tests exactly.
