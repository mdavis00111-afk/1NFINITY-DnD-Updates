1NFINITY D&D v0.0.14 — Character Creator and SQLite build

1. Close your old game. Extract this archive into a NEW folder. Do not delete your old build.
2. Run Launch.cmd. On first launch, Godot imports assets, tests SQLite, and verifies startup before opening the game. No download or Python installation is required.
3. Settings > Set and Store API: enter your Gemini key and model, Test Connection, Save API Settings.
4. Player > Create New: identity, ability scores, skills/spells, loadout/review. Click choices to open searchable options with descriptions. Portraits may remain empty or be supplied later.
5. Player > Generate Character: choose race, class, sex; review the generated choices.
6. Manage Players: save and resume drafts or open a saved character. Deleting archives rather than destroys a character.

Saves: %APPDATA%\1NFINITY_DnD_Godot\players.db. Existing JSON player records migrate on the first player database access; original files remain. Portraits and API settings stay in the same user directory. The API key is masked in the UI but saved locally in settings.cfg (not encrypted). Never share that file. SQLite uses the Windows 10/11 system library winsqlite3.dll via a small PowerShell/C# adapter, not a Python runtime or external database server.

Rules: data/rules.db is the read-only 2014/2018 catalogue. It contains 1,968 entries in 20 categories. A separate reference/private_rules.db contains 169 locally extracted 2018 creature records, not mechanically certified. The original PDFs and reference files are for your personal use and stay outside the update-managed game folder. The revised 2024 rules are not used by character generation.

Testing: Test.cmd imports and runs database, character and layout checks. On first launch the updater runs the SQLite smoke test and main menu check. Keep import.log, sqlite-smoke.log, smoke.log, game.log and any test-*.log if an error occurs. The authoring environment verified SQLite integrity and SQL schema transactions but cannot execute the supplied Windows Godot executable or test a real Gemini key. Windows runtime and visual acceptance remain outstanding. The design is a live-control implementation of the approved mockups, not a screenshot pasted behind fields.

Coverage: All 12 core classes, 9 races, 7 subraces, 12 licensed SRD subclasses, 6 2018 backgrounds and 319 SRD spells; full 2014 PHB non-SRD content not supplied. Current character builder is level one. Ranger favored-enemy details and other unsupported special choices may require review. Campaign schema included for later gameplay, not a playable campaign engine. No revised 2024 mechanics or invented missing source data. GitHub update delivery contains the identical public rules database as a lossless gzip archive, verified by SHA-256 after extraction to the local rules cache. Private reference files stay on your computer. Windows runtime validation remains outstanding.
